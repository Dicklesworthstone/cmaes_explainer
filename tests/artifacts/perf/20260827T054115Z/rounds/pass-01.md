# Pass 01 — rank-μ covariance traversal

Date: 2026-08-27

## Decision

Accepted. Reordering the rank-μ covariance traversal from matrix-element outer / candidate inner to candidate outer / upper-triangle inner reduced the fresh paired 24-D p95 by 15.663687680321047%, well beyond the established 4.8% same-seed envelope. Candidate accumulation order and deterministic outputs remain exact.

## Scope and opportunity

- Mission: reorder/fuse only the rank-μ covariance accumulation hot loop.
- Profile evidence: 24.6% sampled self-time in the rank-μ body plus 6.0% loop/setup, 30.6% combined.
- Opportunity score: `(impact 4 × confidence 5) / effort 2 = 10.0`; eligible because the required minimum is 2.0.
- One lever: traverse ranks first, cache the rank's normalized step and covariance weight, accumulate the upper triangle into the already-existing `provisional` matrix, then apply the unchanged covariance formula.
- No candidate construction, sorting, weighting, normalization, eigensolver, RNG, or snapshot code changed.

## Isomorphism proof

### Ordering preserved

Yes. Before and after, every upper-triangle covariance element starts at positive zero and receives rank contributions in the exact sequence `0, 1, ..., lambda - 1`. The new loop only interleaves independent covariance elements between consecutive ranks; it does not reorder ranks for any element. Candidate generation and the stable fitness/id tie-break remain untouched.

### Floating-point behavior

Identical. The prior term

```text
adjustedCovarianceWeights[rank] * normalizedSteps[rank][row] * normalizedSteps[rank][column]
```

is evaluated left-associatively. The new `weightedRow` caches the same first multiplication and then multiplies it by the same column value. Each element performs the same additions from `0` in the same rank order. The final expression combining old covariance, rank-one, and rank-μ terms is unchanged.

### RNG, tie-breaking, and snapshots

- RNG seeds and draw order: unchanged.
- Fitness sorting and id tie-break: unchanged.
- Positive/negative covariance weight order: unchanged.
- Symmetric writes: still occur only after an upper-triangle element's rank-μ sum is complete.
- Snapshot isolation: unchanged; `provisional` remains generation-local and is consumed by the same eigendecomposition/reconstruction path.
